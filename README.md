# Personal Website

Portfolio website built with Next.js, React, TypeScript, and plain CSS.

Run `npm run build` and `npm run type-check` to validate changes. After a
production build, `npm run perf:assets` inventories the homepage assets;
pass a route with `npm run perf:assets -- /about` to inspect another page.
Measurements and their limits are recorded in [docs/performance.md](docs/performance.md).
